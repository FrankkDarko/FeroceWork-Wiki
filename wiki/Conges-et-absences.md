# Congés et absences

## Demander un congé — pour tout le monde

Tout se passe sur la page **Mes congés** :

1. Choisissez le **type de congé** : congé payé, maladie, deuil, motif personnel, convocation, urgence, congé temporaire, congé sans solde, ou « autre » (dans ce cas, une précision est obligatoire).
2. Choisissez la **durée** : journée entière, matin, après-midi, ou une période entre deux dates.
3. Ajoutez un motif ou des précisions si vous le souhaitez (facultatif), puis envoyez.

La demande apparaît dans votre liste avec son statut : **En attente**, **Approuvée** ou **Refusée** (avec le motif du refus, le cas échéant). Tant qu'elle est en attente, vous pouvez l'**annuler**.

## Traiter les demandes — managers et administrateurs

La page **Demandes de congé** présente la file des demandes à traiter, avec l'historique récent en dessous.

À l'approbation, le manager **classe** la demande :

- **Congé payé** — les jours seront crédités comme travaillés dans le calcul des heures ;
- **Absence justifiée** — les jours seront neutralisés (rien d'attendu, rien de dû) ;
- **Absence injustifiée** — les jours créeront des heures dues ;
- avec, si besoin, l'option **« Décompter »** pour forcer les heures dues quel que soit le type.

Une fois approuvée, l'absence correspondante est **créée automatiquement** pour la période (demi-journée comprise) : elle apparaît en badge sur les [horaires](Horaires) du salarié et entre immédiatement dans le calcul du mois. En cas de refus, un motif peut être indiqué ; le salarié le voit sur sa demande.

## Absences posées directement par un manager

Sans passer par une demande, un manager peut aussi enregistrer une absence directement depuis la page **Horaires équipe** : période, type, option « décompter », motif facultatif. Utile pour régulariser après coup (arrêt maladie transmis par téléphone, par exemple).

## Impact sur les compteurs

Voir le détail du calcul sur la page [Horaires](Horaires). En résumé : un congé payé ne pénalise jamais le salarié, une absence justifiée est neutre, une absence injustifiée crée des heures dues, et une demi-journée compte pour moitié.
