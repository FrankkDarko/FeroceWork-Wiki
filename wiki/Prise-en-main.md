# Prise en main

Ce guide s'adresse à toute personne qui découvre FeroceWork. En dix minutes, vous saurez vous connecter, vous repérer dans l'application et trouver les outils qui vous concernent.

## 1. Première connexion

FeroceWork est une application web : rien à installer, elle s'utilise depuis un navigateur, sur ordinateur comme sur téléphone.

1. Un **administrateur crée votre compte** et vous communique votre identifiant ainsi qu'un **mot de passe temporaire**. Il n'y a pas d'inscription libre : l'accès est réservé aux membres de l'équipe.
2. Connectez-vous avec ces identifiants sur la page de connexion.
3. L'application vous demande immédiatement de **choisir votre propre mot de passe** (8 caractères minimum, à confirmer). Tant que ce n'est pas fait, aucune autre page n'est accessible.
4. Une fois le mot de passe défini, vous arrivez directement sur le tableau de bord — pas besoin de vous reconnecter.

> 💡 **Mot de passe oublié ?** Il n'y a pas de réinitialisation par e-mail : demandez à un administrateur de réinitialiser votre mot de passe. À votre connexion suivante, l'application vous demandera d'en choisir un nouveau.

## 2. Se repérer

La navigation se fait par la **barre latérale** (ou le menu sur mobile), organisée en trois sections :

- **Général** — visible par tout le monde : le tableau de bord, vos horaires, vos congés.
- **Logistique** — visible selon votre rôle : livraisons, arrivages, réceptions, recherche SSCC, incomplets, préparation de commandes.
- **Management / Admin** — réservée aux managers et administrateurs : horaires de l'équipe, demandes de congé, gestion des utilisateurs, journal d'activité.

Vous ne voyez que les entrées correspondant à votre rôle. Si une page vous manque, voyez la page [Rôles et permissions](Roles-et-permissions) ou parlez-en à un administrateur.

## 3. Le tableau de bord

C'est votre page d'accueil. Elle affiche :

- des **compteurs globaux** sur les livraisons (en cours, avec écart, clôturées) ;
- une **carte détaillée de la dernière livraison** : avancement, attendu, compté, surplus ou manquant ;
- un tableau des **écarts par éleveur sur les 30 derniers jours** ;
- l'**activité du jour** : les dernières actions réalisées dans l'application, avec leur auteur ;
- des raccourcis vers la création d'une livraison et l'outil de préparation de commandes.

## 4. Par où commencer selon votre poste

**Vous travaillez à la réception des marchandises :**
1. Consultez les [Arrivages](Arrivages) pour voir ce qui est annoncé.
2. Le jour J, créez une [Réception](Receptions) et scannez les caisses au fil de leur arrivée.
3. En cas de doute sur un carton, utilisez la [Recherche SSCC](Recherche-SSCC).
4. Si un sachet est abîmé ou incomplet, déclarez-le dans les [Incomplets](Incomplets).

**Vous préparez les commandes :**
- Rendez-vous sur [Préparation de commandes](Preparation-de-commandes) pour générer le listing et le picking du jour à partir de l'export des commandes.

**Vous saisissez simplement vos heures :**
- Tout se passe sur la page [Horaires](Horaires). Pensez à régler votre **horaire type** une bonne fois pour toutes : vos journées se pré-rempliront ensuite automatiquement.

**Vous êtes manager :**
- En plus de ce qui précède, vous validez les [demandes de congé](Conges-et-absences) et consultez les [horaires de toute l'équipe](Horaires).

## 5. Les bons réflexes

- **Le scan est prioritaire.** Sur les pages de scan, le champ de saisie reste actif en permanence : posez la douchette, scannez, l'application enchaîne toute seule. Un bip aigu confirme, un bip grave signale un problème.
- **Presque tout est annulable.** Mauvais scan, mauvais comptage, caisse rattachée par erreur : cherchez le bouton **Annuler** avant de paniquer. Les actions sont tracées, jamais perdues.
- **Les filtres sont dans l'adresse de la page.** Une recherche ou un filtre appliqué peut se mettre en favori ou s'envoyer à un collègue : il retrouvera exactement la même vue.
- **En cas de blocage**, consultez la [FAQ](FAQ) ou demandez à un administrateur.
